⬡ Must-Know Facts
  • ZigBee (802.15.4) — low-power wireless for smart home IoT devices
  • UTP twisting — cancels EMI & crosstalk between wire pairs
  • RJ-45 rule — max 1.25 cm untwisted inside connector
  • Fiber optic — immune to EMI, longer distance, more expensive
  • TCP 3-Way Handshake — SYN → SYN-ACK → ACK
  • TCP Sliding Window — Layer 4 flow control, receiver tells sender how many bytes it can accept
  • ARP — resolves IP → MAC address (Layer 3 to Layer 2)
  • Default Gateway — router IP used when destination is outside the local subnet
